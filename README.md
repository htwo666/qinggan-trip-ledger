# 青甘大环线旅行记账台

一个为 4 人 11 天青甘大环线自驾游设计的旅行记账与行程管理工作台。

## 功能特性

### 🆕 v2 新增功能

- 🔄 **双空间切换** — 团队空间（云端同步）与个人空间（仅本地）独立存储
  - 团队空间：所有成员共享同一份云端数据，通过同步码绑定
  - 个人空间：私人记账不上传云端，仅存本地，与团队数据完全隔离
- 💰 **AA 结算助手** — 自动计算"谁应该给谁多少钱"的结算方案
  - 基于付款人字段，精确分摊
  - 贪心算法生成最少笔数的结算清单
  - 兼容老数据（无付款人时按均摊估算）
- 👤 **付款人字段** — 记账时记录是谁付的钱，为结算提供数据基础
- 📝 **反馈入口** — 顶部"反馈"按钮直达 GitHub Issues

### 基础功能

- 📊 **多人记账** — 4 人费用分摊、按人统计
- 🗓️ **行程管理** — 11 天行程规划与记录
- ☁️ **云端同步** — 团队空间基于 textdb.online 实时同步
- 📱 **PWA 支持** — 可安装到手机主屏幕，离线可用
- 📱 **响应式设计** — 桌端与移动端自适应
- 📤 **数据导出** — JSON 备份、CSV 账单
- 📅 **待办日历** — 可视化日历查看待办
- 👥 **成员分工** — 按成员查看负责的物品与待办

## 技术栈

- 纯原生 HTML + CSS + JavaScript（单文件，无外部依赖）
- textdb.online 作为团队空间云存储后端
- localStorage 作为个人空间存储 + 团队空间离线缓存
- Service Worker (Blob 注入) 实现 PWA 离线缓存

## 数据模型

### 团队空间 vs 个人空间

| 维度 | 团队空间 | 个人空间 |
|---|---|---|
| 存储 | textdb.online 云端 + localStorage 缓存 | 仅 localStorage |
| 同步 | 自动同步（30s 轮询 + 写入防抖 2s） | 不同步 |
| 同步码 | 可用（多设备绑定） | 不可用 |
| 主题色 | 青绿色 | 橙色 |
| 预置数据 | 4 人成员 + 3 项预付大项 | 1 人（"我"），无预付 |
| 用途 | 多人协作记账 | 私人记账/纪念品/非团队支出 |
