# 青甘大环线旅行记账台

一个为 4 人 11 天青甘大环线自驾游设计的旅行记账与AI助手工作台。

## 🎉 v3 重磅升级 — AI 旅伴 + 智能同步

### 🤖 AI 旅伴助手（DeepSeek 接入）

- **右下角悬浮按钮** → 弹出聊天面板，支持**流式响应**（边生成边显示）
- **行程感知**：AI 知道今天是第几天、去哪、住哪、天气如何
- **空间感知**：自动区分团队空间/个人空间上下文
- **📍 位置感知**：分享当前位置后，AI 可推荐附近美食/景点
- **6 个快捷问题**：明天去哪 / 当地美食 / 今天穿搭 / 讲个笑话 / 记账贴士 / 高原反应
- **聊天历史持久化**：localStorage 保存最近 50 条对话
- **场景化建议按钮**：
  - 途中管理页每天卡片：🍽 AI 美食推荐 / 🎯 AI 游玩建议 / 🏨 AI 住宿点评
  - 每日穿搭页每天天气行：✨ AI 穿搭建议
- **Markdown 渲染**：加粗、斜体、列表、代码块

### 📲 智能同步方式升级

告别手输 24 位同步码，三种方式任选：

- **扫码邀请**：自动生成二维码，微信/相机扫一扫即可加入
- **分享链接**：`https://htwo666.github.io/qinggan-trip-ledger/?sync=xxx` 一键复制
- **URL 自动绑定**：打开带 `?sync=` 参数的链接，自动弹窗确认加入团队
- **同步码**：保留原方式作为 fallback

### 🔄 v2 双空间切换

- **团队空间**（云端同步）vs **个人空间**（仅本地）数据完全隔离
- 主题色随空间切换：青绿色 ↔ 橙色
- 个人空间禁用同步码按钮，无云端写入

### 💰 AA 结算助手

- 自动计算每人实付/应承担/净额
- 贪心算法生成最少笔数的结算方案（谁给谁多少）
- 记账时记录付款人字段，结算更精确

## 功能特性总览

- 📊 多人记账 + AA 分摊 + 付款人追踪
- 🤖 AI 旅伴（DeepSeek 流式对话、行程感知、位置感知、场景建议）
- 📲 智能同步（二维码 + 分享链接 + URL 自动绑定 + 同步码）
- 🗓️ 11 天逐日行程规划（兰州→西宁→祁连→张掖→敦煌→察尔汗→大柴旦→德令哈→茶卡→青海湖→西宁→兰州）
- ☁️ 团队空间基于 textdb.online 实时云同步
- 📱 PWA 支持，可安装到手机主屏幕，离线可用
- 📅 待办日历 + 成员分工
- 📤 JSON 备份 + CSV 账单导出
- 📝 反馈按钮直达 GitHub Issues

## 技术栈

- 纯原生 HTML + CSS + JavaScript（单文件，无外部依赖）
- DeepSeek API（OpenAI 兼容，流式 SSE）作为 AI 后端
- textdb.online 作为团队空间云存储
- localStorage 作为个人空间存储 + 团队空间离线缓存 + AI 聊天历史
- api.qrserver.com 生成同步二维码
- Service Worker (Blob 注入) 实现 PWA 离线缓存

## ⚠️ 安全提示

**DeepSeek API Key 嵌入前端代码**，任何访问者都能在浏览器开发者工具中看到。建议：

- 使用低余额 / 设置消费上限的 key
- 被滥用时随时在 DeepSeek 后台轮换 key
- 如需更安全方案，可加一层 Cloudflare Worker 代理
